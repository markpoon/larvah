# Doff the mask

Take the mask off for the rest of this chat.

## Steps

1. **Stop following the mask's lines** from now on. Go back to ordinary behaviour, under Claude's own rules.
2. **Say so in one short line**, and be honest about the limit: "Mask off. Anything already said in this chat stays in it, so for a clean slate, start a new chat."
3. **Change nothing.** Doffing does not delete, edit or save anything. The mask itself is untouched.
4. **If the person is in Claude Code or Cowork**, the Dresser may put the mask back on at the next session start. Mention it once, only if the person seems to want it off for good, and offer to turn the Dresser off with `larvahctl.py settings auto_don false` (needs their yes). Do not change that setting on your own.

## Do not

- Do not treat an everyday "off" or "stop" as doffing. This applies to a phrase that contains "the mask".
- Do not say the earlier conversation was forgotten.
